## نصب از AUR

فونت آراد در [AUR](https://aur.archlinux.org/packages/arad-fonts) برای دانلود و نصب بر روی توزیع‌های برپایه آرچ در دسترس است.

```bash
paru/yay -S arad-fonts #Using Aur Helper

git clone https://aur.archlinux.org/arad-fonts
cd arad-fonts
makepkg -sic #manual

```

## مشارکت غیرفنی در فونت آراد
- حمایت مالی و معرفی فونت به افراد دیگر
- بنظر می‌آید فونت آراد، در زبان های کوردی و اردو، حروف جایگزین شرطی، به طور کامل و دقیق پیاده سازی نشدند. باید فونت در این زبان ها آزمایش شود
